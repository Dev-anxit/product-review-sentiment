Database Architecture & Schema

SQLite zero-setup database functioning as both Feature Store and Experiment Registry.

1. raw_reviews

Stores original ingested reviews from Amazon dataset: review_id, product_id, review_title, review_text, rating (1-5), timestamp, helpful_vote, verified_purchase.

2. processed_reviews

Cleaned and normalized text ready for NLP vectorization: cleaned_text (contractions expanded, HTML removed), sentiment (1=Positive, 0=Negative), split ('train' / 'test').

3. experiments

MLOps experiment tracking: records algorithm, hyperparameters JSON, accuracy, precision, recall, F1-score, ROC-AUC, and saved model artifact paths.

4. prediction_logs

Captures every real-time prediction sent through the API with text snippet, predicted label, confidence, probability breakdown, and latency in milliseconds.
